# Content Guide

## 1. Writing Goal

Explain ecommerce and CRO concepts to developers who may have little formal business or ecommerce knowledge.

The writing should feel like an experienced developer explaining something clearly to another developer.

## 2. Writing Style

Always:

- Use simple English.
- Use short, clear sentences.
- Prefer familiar words.
- Explain technical terms before relying on them.
- Use real-world examples.
- Use analogies when they make a concept easier.
- Assume the reader is intelligent but inexperienced.
- Be precise without being academic.
- Use tables for comparisons.
- Use diagrams when relationships are difficult to understand.
- Explain exceptions.
- Distinguish "usually" from "always."
- Make confusing terminology explicit.

Avoid:

- Corporate language.
- Academic writing.
- Unnecessary jargon.
- Long introductions.
- Empty statements.
- Generic AI-sounding prose.
- Overly clever wording.
- Unexplained acronyms.
- Absolute claims when the concept depends on platform or context.
- Treating Shopify terminology as universal ecommerce terminology.

## 3. Standard Concept Page

A normal concept article should generally contain:

1. Title
2. One-sentence definition
3. Simple explanation
4. Real-world example
5. How it relates to nearby concepts
6. Common confusion
7. Shopify implementation, when relevant
8. Developer takeaway
9. Related concepts

Do not force every section when it does not add value.

## 4. Concept Explanation Pattern

Use this mental model:

What is it?
-> Why does it exist?
-> What does it look like in real life?
-> What is it commonly confused with?
-> How does it relate to other concepts?
-> How does Shopify model it?
-> What does a developer need to know?

## 5. Examples

Prefer concrete examples.

For a product/variant explanation, use something like:

T-Shirt
- Black / Small
- Black / Medium
- Black / Large
- White / Small
- White / Medium
- White / Large

Then explain the relationship between product, variant, SKU, barcode, price, and inventory.

## 6. Comparison Content

Comparison pages are a first-class content type.

Examples:

- Product vs Variant
- SKU vs Barcode
- Catalog vs Inventory
- Warehouse vs Location
- User vs Customer
- Merchant vs Vendor
- Discount vs Coupon
- Coupon vs Coupon Code
- Order vs Transaction
- Revenue vs Profit
- Margin vs Markup
- Subscription vs Selling Plan
- Test vs Experiment
- Metric vs KPI
- Personalization vs Experimentation

Comparison pages should answer:

- What does each term mean?
- Where are they similar?
- Where are they different?
- Real-world example
- When would a developer encounter each?
- Shopify terminology, if relevant

## 7. "What Happens When..." Content

Use process articles to connect individual concepts.

Examples:

- What happens when a customer buys a product?
- What happens when inventory reaches zero?
- What happens when a customer applies a discount?
- What happens when a customer returns a product?
- What happens when an order is partially fulfilled?
- What happens when a customer subscribes?

Use flow diagrams where useful.

## 8. CRO Content

CRO content should teach the reasoning process, not just testing tools.

A strong CRO flow is:

Research
-> Observation
-> Insight
-> Opportunity
-> Hypothesis
-> Test plan
-> Experiment
-> Measurement
-> Result
-> Learning
-> Next experiment

Do not reduce CRO to "change button color and run an A/B test."

## 9. Hypothesis Content

A strong hypothesis should connect evidence to an expected behavior change.

Example structure:

Because [observation/evidence],
we believe [change]
will cause [expected behavior]
because [reason].

Then define:

- Primary metric
- Secondary metrics
- Guardrail metrics
- Audience
- Experiment design

## 10. Technical Accuracy

For general ecommerce concepts, acknowledge that definitions can vary by business model.

For Shopify-specific claims:

- Verify against current Shopify documentation.
- Do not invent API behavior.
- Do not assume an object means the same thing across Shopify Admin, Storefront, Liquid, GraphQL, and merchant-facing terminology.
- Clearly label Shopify-specific behavior.
- Prefer official Shopify documentation for technical claims.

## 11. SEO

Write for humans first.

Then ensure:

- One clear page title
- One clear H1
- Useful headings
- Descriptive URL
- Good meta description
- Internal links
- Related concepts
- Breadcrumbs
- Structured data where appropriate

Do not keyword-stuff.

## 12. Content Quality Standard

A page should not be published merely because it contains a definition.

It should help the reader understand the concept well enough to use the term correctly in a technical conversation, API integration, architecture discussion, or CRO project.
