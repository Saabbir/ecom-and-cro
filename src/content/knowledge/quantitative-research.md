## What is Quantitative Research?

**Quantitative Research** analyzes numerical data to answer *"Where and how many users are dropping off?"*

It uses web analytics (GA4, Mixpanel), server logs, and tracking pixels to measure user behavior across millions of sessions.

## Core Quantitative Methods

1. **Funnel Drop-off Analysis**: Identifying which step in the funnel (Cart &rarr; Shipping &rarr; Payment) loses the highest percentage of users.
2. **Form Analytics**: Tracking which input fields cause checkout validation errors.
3. **Heatmap Click Maps**: Measuring click distribution across CTA buttons and links.
